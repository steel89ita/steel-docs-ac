# Extra

The Extra tab provides quick toggles for common scene clean-up tasks that improve photo shot quality.

### Here you can:

- **Disable audio** — mutes all game audio. This setting is saved, so remember to turn it back on the next time you open the game if needed.
- **Hide Pit Crew** — hides pit crew models from the scene without replacing any files.
- **Hide Drivers** — hides all driver models (including AI drivers).

All three settings are persistent across sessions and are restored automatically when Steel Studio loads.

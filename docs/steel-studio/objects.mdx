# Objects

The Objects tab lets you show or hide groups of track meshes without restarting the game. Each entry in the list is defined by the track author in the extension config (see [Objects Config](./track-configs/advanced_objects) for how to set it up).

### Here you can:

- **Toggle visibility** of each defined object using its checkbox.
- **Save Objects** to persist the current visibility state. The next time you open Steel Studio, all objects will be restored to the saved state.

Your objects configuration is saved in `[track_folder]/extension/steelstudio/objects.json` and can be shared with others.
